C3 Global brand kit for Faceless48 Creator (beta 11)
For Dr. CK's own projects only. Not part of the member plug-in.

What is inside
- brand.json: C3 crimson (#C91B19, #A31516, #6F0D0F), copper running into rose gold for the metal, Playfair Display and DM Sans, the orbital globe as the logo.
- public/backdrops/red-velvet.jpg: the crimson velvet background.
- public/brand/orbital-globe.png: the logo.

How to use it in Codex
1. Set up the project with the beta 11 plug-in as usual (it runs the setup for you).
2. Copy brand.json from this kit over the brand.json in the project folder.
3. Copy the two files in this kit's public folder into the project's public folder, keeping the same folder names.
4. Tell Codex, for example: "Make a video carousel in the glass style with the velvet background: background backdrops/red-velvet.jpg, dim 0.3."

Notes
- The velvet works best with the dark styles: editorial, luxe, glass and showcase. Raise dim (0.4 to 0.5) if text is hard to read.
- Music: carousels use tracks from your Drive folder "Cinematic Carousels". Copy the ones you want into the project's public/music folder. They are licensed to you and must never go into the member plug-in.
- Statistics on slides must be checked against the original report before posting.
