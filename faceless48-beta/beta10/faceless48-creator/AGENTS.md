# Faceless48 Creator (package instructions for Codex and other agents)

This folder is the Faceless48 Creator package. Do not edit it. Work in the member's own project folder.

- First time, or "get me set up": read `skills/brand-setup/SKILL.md` and `skills/video-production/SKILL.md`, then create a project with `node tools/create-project.mjs <new-project-folder>`.
- "Make my video", "edit this", "do ya thing": `skills/video-production/SKILL.md`.
- "Edit my yap": `skills/yap/SKILL.md`.
- "Make a life scene": `skills/life-scenes/SKILL.md`.
- "Import my handoff" (a package exported from the Faceless48 Script, Shorts or Thumbnail engine): `skills/handoff/SKILL.md`.
- Music-synced text or the beat picker: `skills/beat-sync/SKILL.md`.
- "Blur my private info" (private details in a screen recording): `skills/redact/SKILL.md`.
- Inside a project, `CLAUDE.md` and `AGENTS.md` repeat these rules and tell you to read `brand-profile.md` first.
- Before the first render of any video, make the storyboard (`npm run f48 -- storyboard <plan.json>`), show the member `sheet.png` and the list in `storyboard.md`, and wait for their approval.
- Run everything locally. Never post, schedule or publish. Never put API keys in chat.
